# 승인 요청 템플릿

주문 직전에 사람에게 보내는 메시지입니다. **여덟 항목이 한 화면에 보여야** 합니다.
하나라도 빠지면 감으로 승인하게 되고, 그러면 승인 게이트를 만든 이유가 사라집니다.

## 슬랙 메시지 형식

```text
🔔 *승인 요청 — 재무 회계팀*

*무엇*      KODEX 200(069500) **1주 매수** · 시장가
*계좌*      모의투자 (실제 돈이 나가지 않습니다)
*현재가*    99,750 원 · 조회 12:40
*보유*      1주 · 평단 99,850 원
*판단 근거*  평단 위 — 조건표 6번(그 외 1주 매수)
*오늘 한도*  1건 중 1건째
*카드*      t_6a8aecb9

승인하시려면 저를 멘션하고 *승인* 이라고 말씀해 주세요.
보류하시려면 *보류* 라고 하시면 됩니다.
```

## 여덟 항목과 그 이유

| 항목                    | 왜 필요한가                                 |
| ----------------------- | ------------------------------------------- |
| **모의 / 실전 표시**    | 가장 위에. 어느 계좌인지 착각하면 안 됩니다 |
| 종목명 + 코드           | 코드만 보면 헷갈립니다                      |
| 매수/매도 · 수량 · 가격 | 판단의 본체                                 |
| 현재가와 조회 시각      | 오래된 시세로 판단하고 있지 않은지          |
| 현재 평단 · 보유 수량   | 이 주문이 평단을 어떻게 바꾸는지            |
| 오늘 한도 소진분        | 한도 대비 어디까지 왔는지                   |
| 판단 근거 한 줄         | 왜 이 주문인지                              |
| 카드 ID                 | 나중에 되짚을 때                            |

## 보내는 법

```bash
hermes -p sam send --to slack "🔔 *승인 요청 — 재무 회계팀* ..."
```

채널을 지정하려면 `--to slack:채널이름` 또는 `--to slack:C채널ID`. 생략하면 홈 채널로 갑니다.

## 승인받는 법

사람이 슬랙에서 이렇게만 말하면 됩니다.

```text
@Sam 승인      → 카드에 승인 기록 → unblock → dispatch → 주문 집행
@Sam 보류      → 사유를 코멘트로 남기고 blocked 유지
```

이 규칙은 담당 프로필의 `SOUL.md` 에 적어 둡니다. 카드 ID를 외우거나 대시보드를 열 필요가 없습니다.

> 💡 **왜 슬래시 명령(`/approve`)이 아닌가** — Hermes 는 크론·칸반 워커를 게이트웨이 승인 컨텍스트로 보지 않습니다. 크론이 슬랙에 승인을 띄우면 듣는 사람이 없을 때 작업이 무한정 멈추기 때문입니다. 그래서 승인을 **카드 상태**로 꺼냈습니다. 워커를 붙들지 않으니 시한도 없고, 승인 기록이 카드에 영구히 남습니다.
