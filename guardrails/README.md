# guardrails/ — 투자 가드레일 문서

자동 집행 루프를 걸기 전에 **사람이 직접 수정하고 확정하는** 안전 규칙입니다.
에이전트는 이 문서를 읽고 따르되, 생성하거나 수정하지 않습니다.

`limits.md`는 강의용 예시값과 `status: unconfirmed` 상태로 제공됩니다. 8.1에서 다음 항목을 자신의 상황에 맞게 수정한 뒤, 모두 확인했을 때만 `status: confirmed`로 바꿉니다.

- 1회 주문 한도 / 1일 주문 횟수 한도
- 매수 금지 조건 (예: 예산 소진 시)
- 오류 시 행동 (재시도 금지 · 보고 · 정지)
- 승인 규칙 (주문 직전 매번 사람 승인)

`status`가 `confirmed`가 아니면 조회만 허용하며, 주문 의도 생성·주문·자동 집행은 중단합니다.
