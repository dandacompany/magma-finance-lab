# backtest/ — 전략 규칙과 백테스트

8.3에서 장기 확정 일봉으로 규칙을 검증합니다.

- `rules.md` — 사람이 확정하는 전략 규칙 5줄 (하루 1회 판정 · 보유 0주면 1주 매수 · 평단 97% 이하면 최대 2주 · 평단 108% 이상이면 전량 매도 · 보유 10주 상한)
- `backtest.py` — `t`일 확정 종가 판단, `t+1`일 시가 체결
- 결과 — 기간·파라미터·비용·초기자금·MDD·회전율·미청산 포지션을 함께 기록
- 보고서 구조는 `contracts/backtest-report.schema.json`을 따릅니다

```bash
python3 backtest/backtest.py \
  --data artifacts/market/market-snapshot-069500.json \
  --start 2014-05-19 --end 2020-12-30 \
  -P 8 -D 3 -Q 10 --cap B
```

파라미터를 앞 구간에서 골랐다면 `--train-start`·`--train-end`로 그 구간을 밝히고,
한 사이클을 손으로 검산해 스크립트와 맞는 것을 확인했다면 `--hand-check-passed`를 붙입니다.

전략과 일괄매수는 같은 초기자금, 시작일, 종료일, 비용 모형을 사용합니다.
보정 구간에서 후보값을 정한 뒤 평가 구간에서는 값을 바꾸지 않습니다.

과거 데이터의 결과는 미래를 보장하지 않습니다. 결과 해석은 "이 구간에서는 이랬다"까지만.
